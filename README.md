# FrameLab

FrameLab è un'app mobile offline-first per fotografi aspiranti, intermedi e avanzati. Trasforma contenuti editoriali verificati in consigli pratici, idee per scattare, sfide e strumenti fotografici.

## Stato del progetto

Il repository ha completato gli Step 1–6: bootstrap Flutter Android/iOS, shell Material 3, onboarding e profilo locale, catalogo offline localizzato con ricerca e dettaglio, e Home con raccomandazioni deterministiche. Lo Step 7A aggiunge soltanto le fondamenta tecniche locali dell'archivio; la relativa UI non è ancora disponibile. Non sono configurati servizi esterni.

## Obiettivo dell'MVP

Offrire onboarding, home personalizzata, catalogo consultabile offline, dettaglio contenuto, archivio personale e profilo fotografico. L'MVP è progettato per accogliere in seguito sincronizzazione cloud, acquisti, pubblicità e analisi AI delle fotografie.
