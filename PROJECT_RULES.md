# Regole di progetto

1. Il catalogo deve restare utile senza connessione; rete e cloud migliorano, non bloccano, l'esperienza.
2. Le decisioni di dominio non dipendono da Flutter, Firebase, Drift o SDK di monetizzazione.
3. Il generatore di idee dell'MVP usa dati e regole trasparenti, non una API AI.
4. Lo stato premium è un entitlement, distinto dalla rimozione pubblicità.
5. Ogni integrazione esterna passa da un adapter e da configurazione non segreta.
6. I dati personali e le foto sono opzionali, minimizzati e cancellabili.
7. Non dichiarare implementata una capacità non verificata con test o controllo manuale.
