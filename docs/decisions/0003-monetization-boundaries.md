# ADR 0003 — Entitlement separati

- **Stato:** Accettata
- **Contesto:** eliminare la pubblicità non equivale a sbloccare funzioni Pro.
- **Decisione:** modellare `removeAds` e `pro` come entitlement distinti.
- **Conseguenze:** paywall, restore acquisti e UI devono verificare il diritto corretto per ogni funzione.
